# INI 일괄 편집기

`D:\exce\<모듈>\setup.ini` 를 모듈별로 한 화면에서 보고 수정하는 도구. Java 8 이상, 외부 라이브러리 없음.

## 실행 (Windows)
1. 처음 한 번 `build.bat` → `dist\IniEditor.jar` 생성 (JDK 필요. 받은 jar가 있으면 생략)
2. `run.bat` 더블클릭 (기본 `D:\exce`) 또는 `run.bat E:\other\root`
3. 에러 확인이 필요하면 `run_debug.bat`
4. 테스트 데이터로 확인: `run.bat test` (Windows) / `./run.sh` (맥) → `TestTemp` 복사본으로 실행, 원본 안 바뀜

## 사용법
1. 루트 폴더 / 파일명 / 인코딩(보통 MS949) 확인 후 **모듈 검색**
2. 위 표는 모듈 x 섹션. 셀에 그 섹션의 `KEY=값` 이 한 줄로 보임
3. 셀을 클릭하면 아래에 `KEY = [입력칸]` 폼이 뜸 → 바로 수정
   여러 곳 동시 수정: Ctrl(맥 ⌘)+클릭으로 셀 추가 (같은 열은 하나만)
   같은 값을 여러 모듈에: 표 왼쪽 '적용' 체크 → **체크한 키 → 체크한 모듈에 적용**
   (폼 줄 왼쪽 체크된 키만 들어감. 값을 고치면 자동 체크, 저장 후에도 유지돼서 나머지 모듈에 이어서 적용 가능)
4. 노란색 = 저장 대기. **저장** 누르면 백업 후 반영 / **변경 취소** 로 되돌림
5. 되돌리기: 각 모듈 폴더의 `setup.ini.bak_시각` 을 `setup.ini` 로 복원
