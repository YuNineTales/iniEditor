# INI 일괄 편집기

여러 모듈 폴더에 흩어진 `setup.ini` 파일을 한 화면에서 조회하고 수정하는 Java Swing 데스크톱 도구입니다.

- Java 8 이상에서 동작하며, 외부 라이브러리를 사용하지 않습니다.
- 수정한 값만 바꾸고 주석, 빈 줄, 키 순서, 공백, 줄바꿈 형식, BOM은 그대로 둡니다.
- 저장하기 전에 원본을 자동으로 백업합니다.

## 폴더 구조 예시

```
D:\exce\
  ├ module1\setup.ini
  ├ module2\setup.ini
  └ ...
```

루트 폴더 아래의 하위 폴더 하나를 모듈 하나로 봅니다. 지정한 파일이 없는 폴더는 건너뜁니다.

## 빌드와 실행

| 작업 | Windows | macOS / Linux |
|---|---|---|
| 빌드 (`dist/IniEditor.jar` 생성, JDK 필요) | `build.bat` | `./build.sh` |
| 실행 | `run.bat` (기본 `D:\exce`) 또는 `run.bat <루트폴더>` | `./run.sh <루트폴더>` |
| 콘솔 로그를 보면서 실행 | `run_debug.bat` | `./run.sh <루트폴더>` |

jar가 없으면 실행 스크립트가 먼저 빌드합니다. 이미 만든 jar는 `java -jar IniEditor.jar <루트폴더>` 로 바로 실행할 수 있습니다.

## 사용 방법

1. **모듈 검색**
   루트 폴더, 파일명(기본 `setup.ini`), 인코딩(기본 MS949, BOM이 있으면 UTF-8로 자동 처리)을 확인한 뒤 **모듈 검색**을 누릅니다.

2. **목록 보기**
   위쪽 표는 행이 모듈, 열이 ini 섹션입니다. 각 셀에는 그 섹션의 `KEY=값` 이 한 줄로 요약되고, 마우스를 올리면 전체 목록이 나옵니다. **섹션 필터**로 원하는 열만 볼 수 있습니다.

3. **값 수정**
   셀을 클릭하면 아래쪽에 `KEY = [입력칸]` 형식의 편집 폼이 열립니다. 고친 값은 노란색으로 표시되며, 줄마다 있는 **되돌리기**로 원래 값으로 돌릴 수 있습니다.
   - Ctrl(macOS는 ⌘)+클릭으로 여러 셀을 함께 열 수 있습니다. 같은 열(섹션)에서는 셀 하나만 고를 수 있습니다.
   - 그 모듈에 없는 키는 `(이 모듈엔 없는 키)` 로 표시되며, 값을 넣으면 새로 추가됩니다.
   - 이름에 `port` 가 들어간 키에는 숫자만 넣을 수 있습니다.

4. **여러 모듈에 같은 값 적용**
   1. 편집 폼에서 적용할 키의 왼쪽 체크박스를 켭니다. 값을 고치면 자동으로 켜집니다.
   2. 위쪽 표의 **적용** 열에서 값을 넣을 모듈을 체크합니다.
   3. **체크한 키 → 체크한 모듈에 적용**을 누릅니다.

   체크한 키만 바뀌고 나머지 키는 그대로 둡니다. 키 체크 상태는 저장한 뒤에도 남아 있어서, 다른 모듈에 이어서 적용할 수 있습니다.

5. **저장**
   **저장**을 누르면 바뀐 모듈만 저장합니다. 저장하지 않은 변경을 모두 버리려면 **변경 취소**를 누릅니다.

## 백업과 복원

저장하기 전에 모듈 폴더마다 `setup.ini.bak_yyyyMMddHHmmss` 백업 파일이 만들어집니다. 원래대로 되돌리려면 이 백업 파일의 이름을 `setup.ini` 로 바꿔 덮어쓰면 됩니다.

모듈 하나가 저장에 실패해도 나머지 모듈은 계속 저장합니다. 실패한 모듈의 변경값은 화면에 남아 있으니 원인을 해결한 뒤 다시 저장하면 됩니다. 실행 중인 프로그램이 파일을 잡고 있으면 저장이 실패할 수 있습니다.

## 참고 사항

- 섹션 이름과 키 이름은 대소문자를 구분하지 않습니다. 같은 섹션에 같은 키가 여러 번 있으면 첫 번째 키를 사용합니다.
- 섹션 밖(파일 맨 위)에 있는 키는 `(전역)` 열에 표시됩니다.
- 값 뒤에 붙은 인라인 주석(`key=value ;메모`)은 값의 일부로 처리합니다.
- 오류가 나면 실행한 위치(현재 작업 폴더)에 `IniEditor_error.log` 가 생성됩니다.
